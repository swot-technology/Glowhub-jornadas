# Jornadas do GlowHub

O GlowHub nas telas de verdade: cada jornada é um vídeo em capítulos, gravado na demonstração, com dados inventados.

- [Financeiro, cada funcionalidade do começo ao fim](https://swothub.github.io/Glowhub-jornadas/financeiro/): os 19 capítulos da parte 7 do guia do Financeiro, gravados em 27/10/2026 (30 minutos).

Os vídeos saem do roteiro do Playwright do repositório `glowhub` (`apps/web/tour`, `pnpm --filter @glow/web tour`) e foram comprimidos em H.264 para tocar em qualquer navegador e celular. A página pede aos buscadores que não a indexem (`robots.txt` e `noindex`), mas é pública: quem tem o link a abre.
